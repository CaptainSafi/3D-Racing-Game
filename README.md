# 🏎️ 3D Racing Game (PyOpenGL)

A simple 3D racing game built with **Python + PyOpenGL + GLUT**.

## 🎮 Controls
- **Enter** – Start / Resume
- **ESC** – Pause
- **← / →** – Change lanes
- **C** – Change vehicle / Toggle God Mode (in-game)
- **W** – Power-up Wiki (Pause menu)

## 🚗 Vehicles
- Sedan
- Sports Car
- Van
- Motorcycle

## ⚙️ Requirements
- Python 3.8+
- PyOpenGL
- PyOpenGL_accelerate
- FreeGLUT

## ▶️ Run the Game
```bash
pip install -r requirements.txt
python main.py
